# Chamos - código base propio

Este es el código completo de Chamos para Android. Nació de Element X Android (v26.10.1,
licencia AGPL-3.0, ver LICENSE) y desde aquí se corrige y se mejora directamente,
sin parches al compilar. Los créditos a Element se mantienen según la licencia.

La firma de la app y las notificaciones push (Firebase) no están en este repositorio:
se aplican al compilar con los secretos del repositorio.
